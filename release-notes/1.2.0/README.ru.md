# 🚀 SmartYard-Server 1.2.0

[English](README.md) | [Русский](README.ru.md)

В релиз вошли push-уведомления об открытии двери по лицу из выбранной группы и улучшенная
автоматическая группировка сохранённых лиц по схожести. Для автомобильных номеров теперь можно указать страну
и срок действия. В WEB-интерфейсе появились журналы событий для администраторов и сводная статистика по квартирам,
оборудованию, RFID-ключам и мобильным устройствам. Также добавлена поддержка домофонов OMNY VDP-10M, OMNY VDP-10S
и сетевого считывателя BAS-IP CR-02BD, а дому теперь можно назначить несколько обслуживающих организаций.

## ✨ Новые возможности

- Добавлена поддержка домофонов OMNY VDP-10M и OMNY VDP-10S.
- Добавлена поддержка сетевого считывателя BAS-IP CR-02BD.
- Добавлено отслеживание открытий по группе лиц: при открытии двери по лицу из выбранной группы
  абонент получает push-уведомление.
- Для автомобильных номеров добавлены код страны, срок действия и проверка формата российских номеров,
  а в мобильном API появился метод `listNumbersV2`.
- В WEB-интерфейс добавлены журналы событий для квартир, входов и домов с фильтрами, предпросмотром и экспортом в CSV.
- Добавлена страница статистики по квартирам, оборудованию, RFID-ключам и мобильным устройствам.
- Дому теперь можно назначить несколько обслуживающих организаций.
- Добавлена поддержка диапазонов архива Forpost.
- Добавлен мобильный API `GET /mobile/address/plogInfo/{eventUuid}` для получения события по UUID. Метод возвращает
  квартиру, название входа, тип события и ссылку на снимок.
- Добавлено подключение конфигурации Nginx для отдельной инсталляции из `/etc/nginx/rbt.d/*.conf`. Эти файлы
  не затрагиваются обновлениями репозитория. Подробнее в [инструкции по Nginx](../../install/08.nginx.md).

## 🛠️ Улучшения

- Автоматическая группировка теперь обрабатывает все сохранённые лица абонента, сохраняет существующие группы
  и добавляет в них новые похожие лица.
- В списках и поиске оборудования теперь отображаются идентификаторы камер и домофонов.
- API синхронизации абонентов биллинга теперь может обновлять настроенные дополнительные поля квартир,
  переданные биллингом по имени поля.
- Настройка email дополнена режимами SMTP-шифрования и таймаутом подключения.

## 🐛 Исправления

- Исправлено формирование URL снимков для Flussonic и Sesame DVR при использовании `secure_token`.
- Исправлена передача адреса видеопотока в push-уведомлении о входящем вызове. Вместо сырого `dvrStream` теперь
  передаётся URL, сформированный DVR-бэкендом.
- Исправлена привязка автомобильного номера к квартире при формировании события открытия LPRS.
- Исправлена обработка SIP-событий в обновлённом формате логов Ufanet.
- Исправлено сопоставление статусов SIP-регистрации Akuvox-совместимых домофонов в Zabbix.
- Исправлен вечный спиннер после закрытия формы добавления камеры без сохранения.
- Исправлена фильтрация видимости камер, которые одновременно привязаны ко входам и к дому.
- Исправлено сохранение режима отображения группы камеры при использовании циклической кнопки для переключения режима.
- Исправлена обработка пустых и вложенных групп камер.
- В ответ мобильного API адресов возвращён идентификатор входа, необходимый для точного сопоставления камер.
- Добавлены отсутствовавшие переводы дополнительных полей квартир для видеонаблюдения.
- Исправлено обновление дополнительных полей квартир пользователями с правом редактирования дома.

## 🔌 Совместимость

- Данные автомобильных номеров перенесены из `houses_flats.cars` в отдельные таблицы. Существующие данные
  переносятся автоматически миграцией PostgreSQL v97, отдельная команда не требуется.
- Изменены контракты пользовательских бэкендов `frs` и `households`. Бэкенды на основе штатных реализаций
  не требуют доработки.

## ⚠️ Обновление

### Отслеживание событий

Для push-уведомлений об открытии двери по лицу из выбранной группы в `/opt/rbt/server/config/config.json`
должно быть включено отслеживание событий:

```json5
{
    "mobile": {
        "events_tracking": true
    }
}
```

### Системная статистика

Новая страница системной статистики в WEB-интерфейсе показывает сводную информацию по квартирам,
оборудованию, RFID-ключам и мобильным устройствам. На существующих инсталляциях страница не включается
автоматически. Если хотите включить её, добавьте следующую конфигурацию бэкенда в
`/opt/rbt/server/config/config.json`:

```json5
{
    "backends": {
        "statistics": {
            "backend": "internal",
            "inactiveDeviceDays": 30,
            "cacheTtl": 300
        }
    }
}
```

`inactiveDeviceDays` задаёт количество дней без активности, после которого мобильное устройство считается неактивным.
`cacheTtl` задаёт время кэширования статистики в секундах.

Затем переиндексируйте права API:

```bash
php /opt/rbt/server/cli.php --reindex
```

### Шаблоны Zabbix

Если вы используете Zabbix для мониторинга Akuvox-совместимых домофонов, после обновления переимпортируйте шаблоны:

```bash
php /opt/rbt/server/cli.php --init-monitoring-config
```

### Пользовательские бэкенды FRS

Бэкенды, напрямую наследующие абстрактный `frs`, должны реализовать или обновить методы:

```php
getFaceGroupIdFrs(int $flat_id, int $subscriber_id, int $face_id): ?int
getFacesFromGroupIdFrs(int $group_id): array
clusterFacesBySimilarityFrs(string $prefix_name, int $subscriber_id, int $flat_id): bool
isLikedFlagFrs($flat_id, $subscriber_id, $face_id, $event_uuid, $is_owner): array
```

`isLikedFlagFrs()` теперь должен возвращать состояние и идентификатор совпавшего лица:

```php
[$is_liked, $registered_face_id]
```

Бэкенды, наследующие `frs/internal`, не требуют изменений.

### Пользовательские бэкенды households

Для групп лиц пользовательские бэкенды `households` должны реализовать:

```php
getSubscriberGroupById($subscriberGroupId): ?string
```

Контракт `households` также расширен для хранения кода страны и срока действия автомобильного номера:

```php
getFlatPlateNumbers($flatId)
getFlatPlateNumbersV2($flatId)
getFlatLicensePlates($flatId)
addFlatPlateNumber($flatId, $number, $validTo = null, $countryCode = 'ru')
removeFlatPlateNumber($flatId, $number, $countryCode = 'ru')
modifyFlatPlateNumbers($flatId, $cars)
updatePlateValidTo($number, $validTo = null, $countryCode = 'ru')
updateFlatPlateValidTo($flatId, $number, $validTo = null, $countryCode = 'ru')
```

Бэкенды, наследующие `households/internal`, получают эти методы автоматически и не требуют изменений.
