## Configure Nginx

```bash
rm /etc/nginx/sites-enabled/default
ln -sf /opt/rbt/install/nginx/rbt_force_ssl /etc/nginx/sites-enabled/rbt
```

Instance-specific `location` directives can be stored in `/etc/nginx/rbt.d/*.conf`. These files are included in the
main RBT server block and are not affected by repository updates.

```bash
mkdir -p /etc/nginx/rbt.d
nginx -t
```
