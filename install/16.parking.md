#### OPTIONAL
#### Parking occupancy service

Finds the free parking spaces of every camera whose parking configuration (the "Parking" tab of the camera form) is ready and enabled, with [FALPRS](12.falprs.md) vehicle detection. Results are shown on the "Result" view of the same tab.

The service needs no npm dependencies (Node.js 20.10 or later).

1. Make the config file and edit it

    ```shell
    cd /opt/rbt/server/services/parking
    cp config.sample.json config.json
    ```

    - `api.internal` - internal API of the server, as `api.internal` of the server config
    - `falprs.url` - LPRS API of FALPRS, `falprs.authToken` - its token if FALPRS requires one, `falprs.timeout` - seconds
    - `listen` - address the service serves the processed frames to FALPRS on, 127.0.0.1 by default: set an external address only when FALPRS runs on another host
    - `frameBaseUrl` - how FALPRS reaches that address
    - `camerasRefresh` - how often the list of cameras to process is refreshed, seconds (300)
    - `cameraTimeout` - timeout of requests to the internal API, seconds

    The processing interval of cameras (`interval`, `minInterval`) and the storage of the processed frames (`storage`: tmpfs or gridfs; tmpfs by default when the `tmpfs` backend is configured, gridfs otherwise) are set in the `parking` section of the server config.

2. Add user and group (if not yet):

    ```shell
    groupadd rbt
    useradd -g rbt -s /bin/true -d /dev/null rbt
    ```

3. Make logging dir:

    ```shell
    mkdir -p /var/log/rbt_parking_service/
    chown -R rbt:rbt /var/log/rbt_parking_service/
    ```

4. Make logrotate:

    ```shell
    echo '/var/log/rbt_parking_service/*.log {
        daily
        missingok
        rotate 7
        compress
        notifempty
        copytruncate
        dateext
        dateformat -%Y-%m-%d
    }' | tee /etc/logrotate.d/rbt_parking
    ```

5. Install and start the systemd unit:

    ```shell
    ln -sf /opt/rbt/server/services/parking/parking.service /etc/systemd/system/rbt_parking.service
    systemctl daemon-reload
    systemctl enable --now rbt_parking
    ```
