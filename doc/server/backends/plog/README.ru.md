# Backend `plog`

## Назначение

Журнал событий доступа (звонки, открытия, лица, транспорт): дни с событиями, детализация по дню, константы типов событий.

События RFID-ключей без привязки к квартире сохраняются отдельно в ClickHouse-таблицу `plog_service`. В нее попадают служебные ключи типов `0` (универсальный), `3` (подъезд), `4` (дом) и `5` (компания), если ключ разрешен для конкретного домофона. Пока таблица только для накопления: API/UI чтения нет (нужна миграция ClickHouse `9`). Backend-хелпер `getServiceEventsByDay` есть для отладки и будущего интерфейса.

## Код

- **Базовый класс**: `server/backends/plog/plog.php`.
- **Варианты**: `clickhouse`.

## Конфигурация

Ключ в `server/config/config.json`: `backends.plog`.

## Основные методы (контракт)

`getEventsDays`, `getDetailEventsByDay`, методы по UUID события и др. — см. файл.

## Кто использует

API журнала, мобильный клиент, интеграция с `households`/`frs`/`dvr`.
