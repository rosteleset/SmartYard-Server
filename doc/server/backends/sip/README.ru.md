# Backend `sip`

## Назначение

SIP-телефония: поиск сервера/параметров по абоненту, STUN для расширения.

## Код

- **Базовый класс**: `server/backends/sip/sip.php`.
- **Варианты**: `internal`.

## Конфигурация

Ключ в `server/config/config.json`: `backends.sip`.

### Транспорт мобильных вызовов

При формировании push входящего вызова `asterisk.php` использует поля выбранного
сервера из `backends.sip.servers[]`:

- `sip_mobile_transport`: значение `tls` включает SIP over TLS. Если поле
  отсутствует, равно `null` или содержит другое значение, сохраняется `tcp`.
- `sip_tcp_port`: порт TCP; прежнее значение по умолчанию: `5060`.
- `sip_tls_port`: порт TLS; при отсутствии поля или значении `null` используется
  `5061`. Можно указать нестандартный порт. Само по себе это поле не включает TLS.

Например, в существующую запись сервера Asterisk можно добавить:

```json
{
  "sip_mobile_transport": "tls",
  "sip_tls_port": 8443
}
```

Перед включением TLS нужно настроить соответствующий транспорт в рабочем
`asterisk/pjsip.conf`, например:

```ini
[transport-tls]
type = transport
protocol = tls
bind = 0.0.0.0:8443
cert_file = /etc/asterisk-tls/cert.pem
priv_key_file = /etc/asterisk-tls/key.pem
method = tlsv1_2
verify_client = no
require_client_cert = no
symmetric_transport = yes
```

Нужна доверенная цепочка сертификатов для доменного имени из поля `ip` сервера.
Предоставьте процессу Asterisk доступ на чтение сертификата и закрытого ключа,
не делая ключ общедоступным, и откройте выбранный TCP-порт в firewall. Примените
конфигурацию перезагрузкой настроек или перезапуском Asterisk в зависимости от
настроек транспорта. При продлении сертификата обновляйте и файлы Asterisk.
Существующие TCP/UDP-транспорты для остальных устройств можно сохранить.

Мобильный клиент должен поддерживать `transport=tls` и передаваемый порт.
Настройка меняет только параметры SIP-сигнализации в push: не включает SRTP,
не меняет RTP, TURN или подключение панели. Она не гарантирует прохождения
вызовов через ограничения оператора.

Регрессионный тест (только PHP CLI, без БД и отправки push):

```sh
php tests/mobile_sip_transport.php
```
